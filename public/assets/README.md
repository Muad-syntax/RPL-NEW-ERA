# Panduan Penempatan Foto

Letakkan file foto pada direktori berikut:

1. **Logo Kelas / Favicon**:
   - Path: `public/assets/logo-rpl2.jpeg`

2. **Foto Pengurus**:
   - Path: `public/assets/images/pengurus/`
   - Format: Portrait (3:4), misal `muad.jpg`, `zein.jpg`, dst.
   - Update path-nya di `src/data/pengurus.json`

3. **Foto Wali Kelas & Guru**:
   - Path: `public/assets/images/pembimbing/` dan `public/assets/images/pelajar/`
   - Format: Rasio 1:1 (kotak/lingkaran)
   - Update path-nya di `src/data/pembimbing.json` & `src/data/pelajar.json`

4. **Foto Kenangan**:
   - Path: `public/assets/images/kenangan/`
   - Daftarkan foto ke dalam `src/data/kenangan.json`
